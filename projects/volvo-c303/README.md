# Project: volvo-c303

*Verkstadshandbok grundfordon* — the Swedish workshop manual for Terrängbil 11
och 13 (Volvo C303/C304). 1028 pp, scanned 200 DPI, no text layer.

This directory holds only **config + git-ignored data**:

```
config.json     # langs, domain context, glossary seed, grid/dpi  (committed)
source/         # Grund.pdf — the scanned manual                   (gitignored)
artifacts/      # everything generated by the pipeline             (gitignored)
  pages/        #   native-res page renders
  marker/       #   Extract IR (marker JSON)
  json/         #   page models (geometry + grid + translations)
  overlay/      #   gridded images the LLM sees
  llm/          #   per-page translate+classify results
  out/          #   composed PDFs (searchable + readable)
  glossary.json #   reconciled canonical sv→en glossary
```

To reproduce: place the source PDF at `source/Grund.pdf`, then run the engine
stages (see repo root `docs/PIPELINE.md`). The source PDF is a copyrighted
document and is not distributed with this repository.
